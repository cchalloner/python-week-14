# Week 14 Lab Part II

1. Open this folder in VS Code (File > Open Folder).
2. Open `week14_lab.ipynb` and follow the steps in the notebook. `week14_demo.ipynb` is the demo from the videos.
3. Your API key goes in a file named `config.py` in this folder. The `.gitignore` here keeps `config.py`, and the copy Python saves in `__pycache__`, out of GitHub. Never commit your key.
4. When finished, restart the kernel, run all cells, and check that the cell numbers read 1, 2, 3, in order. Then stage, commit, and sync your changes, and submit your repository link in Blackboard.
